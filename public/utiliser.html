⚠️ IMPORTANT ORDER

You must click "Start Virtual Camera" before opening apps like Chrome or OBS. If you open the app first, the camera will be hidden.

One-time setup required on the utiliser machine:

  • Install v4l2loopback & FFmpeg (Linux only) sudo apt install v4l2loopback-dkms ffmpeg
  • Or, automatically install dependencies: ./setup.sh
  • Run the server, then click "Start Virtual Camera" above. Apps will instantly detect CamShare.

Windows: Use OBS Virtual Camera or UnityCapture to consume the feed.
